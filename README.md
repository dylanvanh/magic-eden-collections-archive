# Magic Eden Collections Archive

Archive of Magic Eden Ordinals collection snapshots.

Each collection folder in this repo includes:
- `meta.json`
- `count.json`
- `inscriptions.json` (placeholder only)

The full `inscriptions.json` files are not stored in git due to GitHub LFS bandwidth limits.

Download full snapshots from Releases:
https://github.com/dylanvanh/magic-eden-collections-archive/releases
